# Personal Portfolio Website

Este es un proyecto que integra dos retos secuenciales de [roadmap.sh](https://roadmap.sh): [Basic HTML Website](https://roadmap.sh/projects/basic-html-website) y [Personal Portfolio](https://roadmap.sh/projects/portfolio-website). El objetivo principal es construir primero la arquitectura multipágina utilizando estrictamente HTML semántico y metadatos SEO, para posteriormente transformarla en un portafolio personal completamente estilizado, responsivo y adaptable a distintos dispositivos mediante CSS.

## Objetivos del Proyecto

- **Estructura Semántica y Multipágina:** Desarrollar una arquitectura limpia utilizando etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<footer>`, etc.) dividida en cuatro páginas principales: **Homepage**, **Projects**, **Articles** y **Contact**, conectadas por una barra de navegación persistente.
- **Optimización SEO:** Configurar etiquetas `<meta>` esenciales para motores de búsqueda dentro del bloque `<head>` de cada una de las páginas.
- **Formulario de Contacto:** Implementar una página de contacto funcional a nivel estructural con campos adecuados para nombre, correo electrónico y mensaje.
- **Diseño Responsivo y Maquetación:** Aplicar técnicas de CSS como **Flexbox**, **Media Queries** y el **Modelo de Caja (*Box Model*)** para adaptar la estructura base a pantallas móviles y de escritorio.
- **Identidad Visual y Tipografía:** Definir una paleta de colores coherente, estilizar la barra de navegación y el formulario, e integrar fuentes tipográficas mediante **Google Fonts**.

## Tecnologías Utilizadas

- **HTML5**
- **CSS3**
